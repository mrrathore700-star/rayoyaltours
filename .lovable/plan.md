# Remove Experience Category Emojis

## Scope
Remove only the decorative emoji displayed before experience category names. Preserve category names, all text, and the existing design and behavior.

## Implementation
- Remove the emoji display from the shared experience-category page template.
- Leave category content, imagery, layout, styling, and other website areas unchanged.

## Verification
- Confirm the category detail template no longer renders an emoji before its title.
- Confirm the Experiences category listing and category names remain unchanged.
